# Sprint 15c Design: Release preparation (the itch.io launch)

**Status:** Implemented (Sprint 15c). Deviations: there is no separate Licences screen (as section 5 says); itch.io calls a draft page "Private" (verified); the cover is a clean boss-fight frame with the banner, made without the HUD; the version text is bottom right of the home screen; the real export and zip are produced by the workflow on the pull request (no export templates are installed here, so a pack export and the published engine files were used to measure); see `docs/architecture/front-door.md`. Branch `sprint-15c-release-prep`.

The parked third part of Sprint 15 (`docs/release-planning/`), now unparked. Scope comes from the user's answers in conversation; decisions marked "my call" are mine and open to correction.

## 1. Intent

Publish ScrollSmith Survivors on itch.io as **a proper launch, free to play, for strangers to find**. A stranger decides in a few seconds from the page (cover, screenshots, a moving picture, a short pitch) and then in the first minute of play, in a browser tab or on a phone. Sprint 15c makes both ready: the game gets the small things a public release lacks (an icon, a version, licence notices, a web page that says what it is, a rotate hint on a phone held upright) and the repository gets a repeatable way to produce an itch.io upload and the page's words and pictures.

**Goals (user decisions)**
- **Launch kind:** proper, public, free; strangers are the audience.
- **Licence:** **all rights reserved** for the game's code and art ("keep it simple").
- **Delivery, option C:** GitHub Actions builds and checks the itch.io zip and attaches it to the run; the user downloads it, looks at it and uploads it by hand. Nothing goes public without the user, no API key or secret is stored, and `butler` can be added later as one more step.

**My calls (open to correction)**
- **Version `1.0.0`**, set once as `config/version` in `project.godot` and read from there everywhere (Credits, the home screen where it fits, the page text). A test fails if the setting is missing or not `major.minor.patch`.
- **Icon.** A pixel-art wizard-and-scroll icon built in the art pipeline from a `.sprite` source, written as a PNG at a whole-number scale (the one place scaling is unavoidable, as `release-checklist.md` already says) and set as `config/icon`, so the browser tab, the itch.io page and the web export use it. Crisp, never smoothed.
- **Licence notices.** The Credits page gains the copyright line (`© 2026 JTexpo. All rights reserved.`; JTexpo is the name the Credits already use, the user may prefer a legal name), the version, and a "Third-party licences" block for Godot (MIT, with its copyright line) and GUT (MIT, with its copyright line), copied from the licence files each project ships. A `LICENSE` file at the repository root states all rights reserved and says `addons/gut` keeps its own MIT licence (the file stays in place). Everything else shipped (sprites, fonts, tunes, sounds) is made from text sources by the game's own tools, so no other notice is needed.
- **The web page.** Keep Godot's HTML shell and add a `head_include` with the page title, a description, a theme colour, the Open Graph tags (so a shared link looks right) and a viewport meta; a dark page background matching the game's loading colour. The itch.io embed is an iframe the page does not control, so the shell stays minimal.
- **Rotate hint (in the game, not the HTML).** When the game runs in a browser on a touch device whose window is taller than it is wide, a full-window card says "Turn your phone sideways" and disappears the moment the window is wider than tall. It never shows on a desktop browser, in a narrow desktop window, or in landscape; it ignores no touch it should not (see anti-goals). This is the smallest part of the sprint and the first to cut if the schedule or the review asks.
- **The package.** The existing deploy workflow's build job also (a) runs a checker on `build/web`, (b) zips it with `index.html` at the zip's root and (c) uploads the zip as a workflow artifact kept 14 days. It runs on every build (so a limit is crossed in a pull request's follow-up, not on launch day) and by hand from the Actions tab. The checker is a Godot script (`tools/release/`, run with the Godot the workflow already downloads), with the rules in a pure class unit-tested in GUT: `index.html` at the root; at most 1000 files (itch.io's limit as quoted in forum posts; to be confirmed against itch.io's own documentation page by the builder); each file under 200 MB and the total under 500 MB; no two file names that differ only by case.
- **Test before public:** upload the zip to a **draft** (not public) itch.io page, play it in itch.io's own frame on a desktop and on a phone, and only then make the page public. The builder verifies that itch.io drafts can be hidden this way and writes the exact steps.
- **Page content as a document:** `docs/release-planning/itchio-page.md` holds everything the user pastes into the itch.io form: title, a one-line tagline, the description, a controls table (taken from `ControlsText`, kept in step by a test), a feature list, genre and tags, the "made with Godot" mention, the licence line, the embed size (a whole multiple, 960 by 540 or 1440 by 810) and the settings to tick (fullscreen button, mobile-friendly).
- **Promotional pictures** (`docs/release-planning/promo/`, committed PNGs and one GIF): a cover image (about 630 by 500, itch.io's recommendation, to be confirmed), 4 to 5 screenshots of real play (home, a fight with several spells, crafting at the Lectern, a boss, the map select) and a short looping GIF of a fight. All come from the real game by throwaway scripts in the existing scratchpad style (a throwaway save, `--resolution` at a whole multiple of 480 by 270, nearest-neighbour only). The cover is composed from the game's own sprites. The user judges every picture. If a GIF needs a library, **Pillow goes in the gitignored `venv`** (the user's rule keeps installs there; it is not installed today), never globally.
- **Stale addresses:** the published address in `CLAUDE.md` becomes `https://jtexpo.github.io/ScrollSmith-Survivors/`; a `docs` grep shows no old address left; the checklist item is ticked.
- **Docs:** `docs/architecture/front-door.md` gains "Release preparation (Sprint 15c)" (heading also in `tests/fixtures/claude_md_sections.txt`), `release-checklist.md` and `itchio-notes.md` are updated with what is done, `development-log.md`, `sprint-development.md` marks 15c built, `future-roadmap.md` is updated, and `CLAUDE.md` gets the index and Project State lines.

**Non-goals**
- Any gameplay, balance, map, enemy or spell change; new content; a trailer video; paid features, tip jars or a donation link; leaderboards, analytics or crash reporting; desktop or mobile-store builds; translations; a PWA; automated publishing with `butler`.
- Removing the `iPhone` browser toolbar or the web full-screen limits (accepted earlier as a web limitation).
- Deciding for the user the price, the page's visibility date or the page's category; the user creates the itch.io page.

**Anti-goals** (a failure even if it technically works)
- A zip itch.io rejects or cannot run (`index.html` not at the root, too many files, a case mismatch), found only on launch day.
- Two different version numbers on screen, in the page text or in `project.godot`.
- A blurry or smoothed icon, or an icon that is not square.
- A rotate hint that shows on a desktop, covers a landscape game, stays after the phone is turned, or swallows touches in landscape (it must never leave a hidden full-window control that blocks input, `test_world_input` stays green).
- Licence text that is wrong or invented: notices are copied from the files the projects ship, not written from memory.
- Promotional pictures that show something the game does not do (every picture is a real frame of real play, no mock-ups, no fake features).
- A secret, API key or the user's email in a committed file, the workflow or the page text.
- A test that touches the real save or settings, or really changes scene.

## 2. Approaches

- **Delivery of the zip.** A: a local script (needs Godot's web export templates installed on the user's machine, against their keep-tooling-isolated rule; workable only from a throwaway copy). B: GitHub Actions publishes with `butler` on every release (needs an API key as a repository secret, goes public without a human look). **C (the user's pick):** Actions builds and checks the zip, the user uploads it by hand; no secret, no local templates, nothing public unseen, `butler` can be added later.
- **Where the packaging lives.** A second workflow duplicating the Godot download, or one more step in the existing build job. **One step in the existing job (my call):** no copied 40 lines, the same pinned Godot, a limit check on every build.
- **Web page.** A full custom HTML shell (a loading screen, a rotate message, everything in HTML) or Godot's shell with a small `head_include` (my call). The full shell is more to maintain and does little inside itch.io's iframe; the rotate hint is in the game because that is the one place that knows touch, window size and the front door.
- **Icon scaling.** Scale the 16 by 16 or 32 by 32 sprite by a whole number (my call, crisp), versus drawing a large icon (breaks the one-pixel-size look).

## 3. What is left to the builder
- The icon's drawing (a wizard and a scroll, bright and simple, the user's art taste) and its sizes; the exact wording of the page text, tagline, tags and the GIF's length and frame rate within itch.io's size limits for covers and screenshots (to be confirmed); the rotate card's look inside the existing theme and where the version fits on the home screen (Credits always shows it; the home screen only if it clears the button row and corner buttons); the checker's output format; the steps for an itch.io draft upload.

## 4. Verification plan
- **Version:** `config/version` is present and `major.minor.patch`; Credits shows it; the page document shows the same string (a test reads both).
- **Credits and licence:** the Credits lines include the copyright line, the version and a notice for Godot and for GUT whose text matches the copyright lines of `addons/gut/LICENSE.md` and the Godot licence text in the repository's notice; a `LICENSE` file exists and names `addons/gut`; `docs` mention no old address.
- **Icon:** `config/icon` names an existing PNG that is square; the web preset's `html/export_icon` is on; a contact-sheet look at the icon at its real size.
- **Web page:** `head_include` has the title, description, theme colour and Open Graph tags (a test reads `export_presets.cfg`).
- **Rotate hint:** a pure function `RotateHint.should_show(window_size, is_web, has_touch)` is tested for portrait phone, landscape phone, portrait desktop (never), square, and a resize both ways; the node ignores touches and is hidden (not just transparent) in landscape; a real-window check of a portrait window and a landscape one.
- **Package:** `ItchZipRules` is tested for each rule (missing `index.html`, a nested `index.html`, 1001 files, a 201 MB file, total over 500 MB, two names differing by case, a clean set); a guard test reads the workflow and fails if it stops running the checker, zipping or uploading; and one real run of the workflow's build job on GitHub shows the artifact (the user runs "Run workflow", or the first push of this branch's merge does).
- **Page and pictures:** the controls table equals `ControlsText`; every promo file exists at its stated size; contact sheets looked at; the user approves each picture.
- **Whole:** the full suite, the smoke run, the stress and soak numbers unchanged (no gameplay code changed), the web export re-run from a throwaway copy as `CLAUDE.md` describes.
- **By the user (not done by me):** hearing the sound on the live site and in itch.io's frame, a phone playtest through the manual checklist in `release-checklist.md`, creating the itch.io page, the draft upload and the final publish.

## 5. Settled after the builder check (my calls, open to correction)
- **Licences, where they live.** The Credits page is a fixed 464 by 200 label that holds about 20 lines, so it carries short notices only: the copyright line, the version, "Made with Godot 4 (MIT licence)" and a pointer to `licences.txt`. The **full text** is a file, `licences.txt`, that the packaging step writes next to `index.html` from the engine itself (`Engine.get_license_text()`, `get_license_info()` and `get_copyright_info()`, so it is never typed from memory and includes the engine's bundled libraries) plus the game's all-rights-reserved line; the checker fails the zip if it is missing. GUT is **not** in the web build (`addons/gut/*` is excluded), so it needs no notice in the game; the repository `LICENSE` names it. The Credits keep their existing "and GUT" line only as a thanks. If you want the full texts readable inside the game, that is a paged screen and a later sprint.
- **Copyright sign.** The UI font is ASCII only, so the line reads `Copyright 2026 JTexpo. All rights reserved.`.
- **Pull requests.** The one workflow also runs on `pull_request` (build, check and zip only); the deploy job runs only on a push to `main` or by hand, so a limit problem shows on the pull request. No second workflow.
- **Addresses.** The repository rename is confirmed (the old address redirects, `https://jtexpo.github.io/ScrollSmith-Survivors/` answers). The `head_include` carries `og:title`, `og:description` and `og:type` only: no `og:url` or `og:image` (they need one absolute address and a hosted file, and itch.io builds its own link card from the page's cover). The Pages build stays live as the test build.
- **Rotate card and the game.** While the card shows, the game is paused (through `GamePause`) so the player cannot die unseen. The card un-pauses only if **it** paused (if the pause menu or a pick screen already paused, it leaves that alone, and it does not un-pause when turning back).
