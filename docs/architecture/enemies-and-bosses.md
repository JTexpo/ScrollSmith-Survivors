# Enemies and bosses

Archetypes and elements, difficulty, the brains and the boss state machine. Moved word for word from `CLAUDE.md`, one `##` section per sprint. Sections name each other (for example "see Obstacles"); find them in this folder (the index is in `CLAUDE.md`, "Where the detail lives").

## Enemies and bosses (Sprint 11)

- **An enemy is an archetype plus an element, picked independently by weight (user decision, "mix and match").** `EnemyArchetype` (`resources/enemies/archetypes/`: Standard, Swarmer, Chaser, Tank, Ranged, Exploder, Support) holds every stat, the body size, the behaviour (`EnemyBehaviorData`), the unlock time, the cluster size and the drop-chance scale. `EnemyElement` (`resources/enemies/elements/`: none, Fire, Thunder, Land, Sea) holds only the affinity, the colour and the themed drop table. **An element never changes a stat**: a Thunder Tank is as tough as a Land Tank. `EnemyComposer` builds one cached, shared `EnemyData` per pair (names like "Thunder Tank").
- **Shared data is never edited.** Per-spawn values live on the `Enemy` instance: `apply_scales` (difficulty) and `make_elite(EliteModifier)` (x3 health, x1.5 damage, x1.15 speed, x1.4 size, x3 rewards, x2 drop chance, an outline), both worked out from base values so they never compound. `xp_reward()`, `gold_reward()` and `drop_chance_scale()` are what the droppers read, and `gives_rewards` is false for an Exploder that blasted itself.
- **Behaviour is a brain, chosen by the archetype's kind.** `EnemyBrain.for_data` gives `BrainChase` (the old movement), `BrainKeepDistance` (Ranged: holds about 90 px and fires `EnemyProjectile`s), `BrainExplode` (stops, fuses with a `BlastZone`, dies in its blast with no rewards, and the blast is cancelled if the player kills it first) or `BrainSupport` (heals other enemies in range every 0.25 s). Nothing branches on an enemy name.
- **Telegraph rule.** `EnemyProjectile` (cap 60) and `BlastZone` (cap 40) are shared by enemies and the boss. A blast zone is harmless until its fuse ends, never moves, checks the player once, and counts `_process` deltas so it freezes while paused. Every boss attack has a warning.
- **Difficulty.** `DifficultyCurve` (`resources/enemies/difficulty_curve.tres`) maps run seconds to health, damage and speed scales, the spawn interval, the maximum alive, the elite chance and the boss interval. `RunClock` (static) is the pausable run clock: it reads `GameTime` from a start marker that `Main` resets (`GameTime.reset()` alone does not zero it). The spawner unlocks archetypes by time, spawns Swarmer clusters, and `spawn_rate_scale` halves spawning while a boss lives.
- **Bosses are data.** `BossData` (phases, rewards) with `BossPhase` (a health threshold, an attack list, an interval, a speed multiplier) and `BossAttack` (SLAM, CHARGE, BURST, SUMMON and, since 16b, LIGHTNING, with their numbers; since 16d a CHARGE can chain through `repeats`). `Boss` is one state machine (IDLE, TELEGRAPH, ACT, RECOVER) that runs any `BossData`: it ignores knockback, stays in the arena, takes +50% damage after a charge, and a hit that skips a phase lands in the last one it reached. `RunDirector` spawns a boss at 300 s and 300 s after the previous one spawned (never two at once), cycles the roster (the map's own `MapData.bosses` when it names any, else the spawn config's; see Sprint 16b), scales each boss by its number and pays XP, Gold (both times the number) and Rare scrolls where it died. The run continues after a boss (user decision).
- **Stress.** The stress scene starts the clock at `--minutes` (default 5), has `--boss`, and keeps its enemy count with `spawn_at(position, cluster_limit)`.
